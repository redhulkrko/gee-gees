# Gee-Gees

A Phaser 3 sprite race game, designed to run full screen on a TV.

## Running locally

Browsers block loading modules and images from `file://`, so serve the folder:

```
npx serve
```

or use the VS Code **Live Server** extension, then open the address it shows.

## Branches

- `main` – stable
- `dev` – integration branch; feature branches are merged into `dev` and then deleted
